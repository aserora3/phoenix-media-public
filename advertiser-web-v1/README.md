# 広告主向けWeb v1

ゼロベース再設計版。既存営業OS/SNS環境を壊さないため、`advertiser-web-v1` ブランチ配下で独立開発する。

## 現在実装済み
- 公開トップ
- 媒体説明
- 料金プラン（価格は未設定・可変前提）
- 会社情報/担当者情報/媒体/プラン/支払方法/広告内容の申込フォーム
- 代理店紹介欄（報酬率等は非表示）
- デモ案件管理番号発行
- 銀行振込案内
- 掲載開始条件表示
- 長期月払い20日前後通知/25日締めルールの仕様化
- 不可抗力48時間免責＋以後24時間ごとの日割り返金ルール
- 契約主要条項ドラフト
- Cloudflare Pages / Workers / D1 / R2 を使うバックエンド設計

## 重要
現在の申込フォームはフロント初期版であり、送信しても実際の契約・メール送信・データ保存は行わない。バックエンド接続後に本番化する。
